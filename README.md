# I.H.L
Independent Home Lab
My Homelab
Im building my own media server and slowly turning it into a proper homelab. Id rather host my own stuff.

What it does right now
A Jellyfin media server running in Docker on an old PC, so I can stream my own movies and shows to my phone and TV. I get to it from anywhere using Tailscale, so I never had to open up my home network to the internet.

What I'm using

Debian for the operating system
Docker + Docker Compose to run everything
Jellyfin for the media
Tailscale for remote access

Where its headed

More storage
Splitting services into separate VMs with Proxmox
Locking it down properly — firewall, SSH keys, monitoring 

Itll grow as I figure more out
